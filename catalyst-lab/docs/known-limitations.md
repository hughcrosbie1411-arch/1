# Known limitations

- Two-security daily snapshot is a selected illustrative universe, not an unbiased research panel. It cannot support six validated models or intraday reaction estimates.
- Exact historical catalyst labels, historical consensus vintages, options/positioning history, delisted companies, sector/factor panels and execution cost data are missing.
- Forward-adjusted bars may incorporate later corporate-action adjustments. Prices must be checked for point-in-time suitability before feature training.
- No automatic primary-source ingestion, calendar sync, outcomes collector, training/retraining job, champion, live scorecard, authentication or persistent database is operational.
- SQL migration is supplied but not applied/tested against PostgreSQL. Triggers do not replace access control or privileged-user tamper protection.
- Source licensing and public redistribution have not been resolved. Snapshot availability must not be interpreted as real-time freshness.
- No out-of-sample predictive validation, profitable strategy, statistically reliable event comparables or deploy URL is claimed.
- Manual date alignment/daily returns are exploratory. They do not model exact announcements, executable fills or causal effects.

Diagnostics and UI must display missing evidence explicitly. Abstention is preferable to fabricated probabilities.
